# 1. PRIMARY OBJECTIVE\
\
Build a production-grade **event-driven architecture** that connects the entire LeadNexus AI X platform through reliable, versioned, observable, tenant-isolated, idempotent events.\
\
The platform must support:\
\
```text\
DATABASE CHANGE\
→ DOMAIN EVENT\
→ EVENT BUS\

→ EVENT CONSUMER\
→ PROJECTION\
→ WORKFLOW\
→ RESEARCH\

→ AI\

# 2. ABSOLUTE RULES\
\
1. PostgreSQL remains the canonical source of truth.\
2. Events are not automatically the source of truth.\
3. Event streams must be durable and replayable.\
4. Every event must have a unique ID.\
5. Every event must be versioned.\
6. Every consumer must be idempotent.\
7. Events must be tenant-scoped.\
8. Cross-tenant events are forbidden.\
9. Event payloads must respect data classification.\
10. Sensitive data must not be broadcast unnecessarily.\
11. Event schemas must be governed.\
12. Breaking event changes require versioning.\
13. Event ordering must never be assumed globally unless explicitly guaranteed.\
14. At-least-once delivery is the default.\
15. Exactly-once behavior may only be claimed where technically proven.\
16. Duplicate delivery must be safe.\
17. Failed messages must enter controlled retry/DLQ paths.\
18. Replay must be bounded and audited.\
19. Consumers must not execute arbitrary code from event payloads.\
20. AI cannot publish privileged operational commands.\
21. External web content remains untrusted.\
22. Google Sheets remains optional.\
23. CRM is not implemented.\
24. Automatic outreach is not implemented.\
\
